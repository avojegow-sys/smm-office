# SMM-офис

Пиксельная обучающая игра для SMM-щиков: строишь отдел, нанимаешь людей, ведёшь клиентов и разбираешь метрики (CPA, ROAS, ER, CTR, охват).

Это один статический файл `index.html`: без сборки и без сервера. Откройте его в браузере или выложите на любой хостинг статики (Vercel, Cloudflare Pages, GitHub Pages).

Игра рассчитана на телефон (вертикальный экран). Звук включается после первого нажатия.
